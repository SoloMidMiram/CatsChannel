# Environment

Recommended:

- Python 3.11 (current patched release); CI runs the supported 3.11 line
- uv
- aiogram 3
- PostgreSQL for production
- SQLite for local tests
- Redis only when distributed state is required

See [QUICKSTART.md](QUICKSTART.md) for local venv commands and the future 3.13
migration rehearsal. Python 3.13 is not part of the current support contract.
