## Limits and follow-up

The tested isolated path is Linux/WSL plus bubblewrap. No equivalent native Windows
sandbox was validated. Serena was read-only, offline, memories-disabled and limited
to five semantic tools. Context7 was credential-free, had no source mount, and was
limited to generic public-library queries. Filtering cannot prove detection of all
possible secret encodings.

The checked-in helpers package only the repaired policy/transport boundaries and
offline regressions. They do not reproduce the benchmark, install dependencies,
activate MCP, add a bot dependency, or claim an adoption benefit. A future
version-benefit experiment must validate explicit upstream version IDs before
broadening the guard allowlist, preregister an evidence-matched design, and obtain
actual natural tool use or use a separately analyzed intervention.

Packaging review subsequently required six launcher/protocol corrections: writable
external Serena project metadata under a read-only source view, termination of the
reported sandbox child session rather than only its wrapper, preservation of an
external WSL resolver target and uv managed-Python aliases, inclusion of
initialization/inventory failures in health verdicts, and typed guard rejection
that leaves the connection usable. Focused offline and real-bubblewrap regressions
cover those boundaries; they do not change the experiment's **REVISE** decision.

A further focused audit reproduced two remaining policy/measurement faults:
unsupported string-valued protocol methods bypassed query filtering, and arbitrary
nonempty tool text or malformed initialization results could pass the health
check. The correction restricts negotiation/discovery parameter shapes and
requires a valid initialization, expected library resolution and matching public
documentation references. Offline negative controls failed before the fix and
pass afterward. The retained base-ID policy and experiment conditions are unchanged.

Real packaged Context7 resolution, source-backed lookup, local policy rejection
and subsequent valid lookup passed. Real packaged Serena initialization succeeded,
but its first semantic call failed because `uv`/`uvx` was unavailable in the
sandbox PATH. This is a remaining language-server prerequisite, not a reopened
project-metadata, interpreter-alias, DNS or process-ownership finding. Semantic
acceptance remains blocked; retain the draft and do not infer readiness from CI.

Local Python 3.11 validation of this focused correction: 49 MCP tests passed,
1 platform case skipped; the full suite passed 506 tests with 62 skips. Ruff,
formatting, byte compilation and whitespace checks passed. The failing semantic
call left tracked source unchanged and all observed owned processes terminated.
